API JavaScript

Controllo Programmatico

Utilizza l'API JavaScript per un controllo granulare del player.


// Inizializzazione via JavaScript API
const demoPlayer = new YTBackground('#interactive-player', {
  videoId: 'aqz-KE-bpKQ',
  mute:    true,
  loop:    true,
  start:   0,
  controls: false,
  overlay: 0.2,

  // Callback quando il player è pronto
  onReady: (event, instance) => {
    console.log('Player pronto!', instance);
  },

  // Callback per i cambi di stato
  onStateChange: (event, instance) => {
    console.log('Stato:', event.data);
  }
});

// Metodi disponibili sull'istanza:
demoPlayer.play();          // Avvia
demoPlayer.pause();         // Pausa
demoPlayer.mute();          // Silenzia
demoPlayer.unmute();        // Audio
demoPlayer.changeVideo('id'); // Cambia video
demoPlayer.resize();         // Ricalcola
demoPlayer.destroy();        // Cleanup
Documentazione

Come Integrare YTBackground

1. Metodo Dichiarativo (HTML) 


<!-- Includi la libreria -->
<script src="ytbackground.min.js"></script>

<!-- Aggiungi data-attributes al tuo elemento -->
<div
  class="hero"
  data-yt-bg-id="YOUR_VIDEO_ID"
  data-yt-bg-mute="true"
  data-yt-bg-loop="true"
  data-yt-bg-start="0"
  data-yt-bg-controls="false"
  data-yt-bg-overlay="0.4"
>
  <div class="your-content">
    Il tuo contenuto qui sopra...
  </div>
</div>

<!-- La libreria si auto-inizializza! -->

2. Metodo JavaScript (Controllo completo) 


// Auto-init manuale (disabilita quello automatico)
const instances = YTBackground.autoInit();

// Init su elemento singolo
const bg = new YTBackground('#my-element', {
  videoId: 'dQw4w9WgXcQ'
});

// Disabilita auto-init globale via meta tag
<meta name="ytbg-no-auto-init">

// Ottieni tutte le istanze
const all = YTBackground.getInstances();

// Distruggi tutto
YTBackground.destroyAll();

// Versione libreria
console.log(YTBackground.version); // "1.0.0"
